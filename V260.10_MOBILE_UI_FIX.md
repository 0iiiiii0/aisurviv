# V260.10 Mobile UI Fix

Base: V260.9 dual-AI spectator-link fix.

## Scope

This release changes mobile/responsive UI only. Server gameplay, shared game logic, AI, zombies, extraction, authentication, matchmaking, maps, physics, inventory and damage logic are unchanged.

Changed production/source files:

- `client/css/app.css`
- `client/css/game.css`
- `client/dist/index.html`
- `client/dist/css/mobile-v2610.css` (new cache-busted mobile override)

## Fixes

1. Removed the legacy 216/230px nested scroll from the mobile start menu.
2. Removed the 360px empty left-column spacer that pushed the main menu below short landscape screens.
3. Reordered mobile panels so the primary start/team panel is first; extraction follows it only when enabled.
4. Converted extraction on mobile to natural document-flow height, removing its nested vertical scrollbar.
5. Converted the mobile team menu to natural-height one-column flow; `Leave Team` is no longer absolutely positioned outside short screens.
6. Made zombie/account login dialogs responsive to 320/360/375px phones.
7. Added dynamic viewport (`100dvh`) handling where needed.
8. Added iPhone safe-area padding for the start screen and key in-game HUD anchors.
9. Increased key mobile/coarse-pointer tap targets.
10. Added a unique production CSS file name (`mobile-v2610.css`) so clients cannot keep using the old cached mobile layout after upgrade.

## Device-emulation regression

Chromium DevTools Protocol mobile emulation was run against the exact production DOM/CSS using these viewports:

- 320x568 @3x
- 360x800 @3x
- 390x844 @3x
- 844x390 @3x landscape

Key measured results:

- 320x568 start menu: `clientHeight=590`, `scrollHeight=590`, `overflow-y=visible` (no 230px nested menu scroll).
- 390x844 start menu: `clientHeight=590`, `scrollHeight=590` and fits the page without internal clipping.
- 844x390 landscape: start menu begins at about `y=56px`; the old blank 360px left-column spacer is gone. The page itself scrolls vertically when needed.
- 320x568 team menu: `Leave Team` is inside the panel at about `y=112..152px`; no bottom overflow.
- 320x568 zombie dialog: width 300px, x=10px, right=310px (no horizontal overflow).
- 320x568 account-login dialog: width 300px, x=10px, right=310px.
- Extraction section on 320x568: `clientHeight=306`, `scrollHeight=306`, `overflow-y=visible`; only the page-level scroll remains.
- No horizontal overflow was detected in main/team/extraction/zombie/login states across all four viewports.
