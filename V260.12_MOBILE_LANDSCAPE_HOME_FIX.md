# V260.12 Mobile Landscape Home Fix

## Goal
Rework the mobile home screen around the original surviv.io landscape-first layout instead of stacking every panel vertically in landscape.

## Runtime changes
Only four runtime client files differ from V260.11:

- `client/index.html`
- `client/dist/index.html`
- `client/css/mobile-home-v26012.css` (new)
- `client/dist/css/mobile-home-v26012.css` (new)

No server, shared, AI, game-physics, matchmaking, account, zombie, extraction, or in-game HUD source was modified.

## Layout behavior

### Landscape phones (<=1024px wide, <=600px high)
Three-column surviv.io-style home layout:

1. Left: normal + secret Extraction
2. Center: account/server/core modes/team/spectate/help
3. Right: What's New announcement

Short 568x320-class screens use compact controls and independent panel scrolling only where necessary. Extraction and announcements remain visible in the first screen.

### Portrait phones
Keeps the V260.10 single-page compatibility flow:

1. Main menu
2. Extraction
3. What's New

The legacy portrait rule that hid the news column is explicitly overridden.
