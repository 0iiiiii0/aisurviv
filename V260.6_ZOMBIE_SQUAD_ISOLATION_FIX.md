# V260.6 Zombie Squad Isolation Fix

## Bug
When one real player starts Zombie mode in Squad (4-player) mode with auto-fill enabled, spawned zombies could consume the survivor squad's empty teammate slots and appear as teammates.

## Root cause
`ZombieModeSystem.spawnZombie()` created each zombie with a `serverBot=true, autoFill=true` join token. In Duo/Squad, generic `PlayerBarn.findFreeGroup()` therefore considered the survivor's auto-fill group eligible for the zombie. The existing hostile-AI/human roster isolation only covered extraction mode, not zombie mode.

## Fix
1. Zombie spawn tokens now use `autoFill=false`. Zombies are hostile world actors and do not participate in survivor matchmaking groups.
2. `PlayerBarn.findFreeGroup()` now applies the same human/serverBot hard isolation to zombie mode as extraction mode. This is a defense-in-depth guard in case a future zombie/hostile-bot producer accidentally uses `autoFill=true` again.
3. `zombieTeamModeSmokeTest.ts` now includes a direct regression: Zombie Squad + one human + auto-fill + full zombie wave; every zombie must have a different `groupId` and `teamId` from the survivor.

## A/B verification
- Original V260.5: regression fails with `zombie must not occupy survivor squad group`; observed human and zombie `groupId` both equal `1`.
- V260.6: one human + 40 zombies passes with no mixed group/team.
- Additional regressions passed: zombie visibility, zombie no-gas, extraction human/serverBot isolation, TypeScript `--noEmit`.
