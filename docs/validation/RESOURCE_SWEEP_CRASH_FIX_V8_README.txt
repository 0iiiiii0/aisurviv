V8 installation
===============

1. Stop the launcher, game server and all related node.exe processes.
2. Extract the update-only archive into the project directory containing server, client and shared.
3. Allow all matching files to be replaced.
4. Restart the server and create a new room.

This package is cumulative and is based on Integrated AI V7. It retains:
- 50v50 one AI per second, 20+20 AI cap
- deterministic 1v1 firing and repositioning
- cover-gated combat healing
- spectator repair and all-mode auto-fill
- resource-dropping obstacle search and destruction
