combat healing, and loot wall tunnelling.

1. Stop the launcher/server and every related node.exe process.
2. Extract the update-only ZIP into the project root.
3. Overwrite matching files.
4. Restart and create a new room.
5. Static client/dist deployments must rebuild the client on the target Windows machine.

All auto-filled rooms, including private invite/duel rooms, connect one AI every
two seconds. 50v50 remains capped at 20+20 server AI.
