## 结论

主要弱点不是单一命中参数，而是决策层级冲突：

- 近距离/最终开火兜底能够绕过精确掩体判定。
- 高移动散布武器在约一半开火帧中仍在移动。
- 手雷会抢占仍可使用的枪击窗口。
- 旧出掩体逻辑只预测位置，没有根据子弹飞行时间安排开火。
- 反弹武器资格与服务端真实弹丸规则不一致。
- 敌人回掩体治疗后缺少稳定的“露出点射击 → 反弹 → 手雷 → 侧翼”策略链。

机器可读详细数据见 `V40_DUEL_LOG_ANALYSIS.json`。
