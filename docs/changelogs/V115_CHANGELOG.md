# V115 撤离成功提示并自动返回仓库

## 问题

- 搜打撤撤离完成后，客户端停留在"撤离中 0.0"没有成功提示，
  也不会回到仓库页（服务端已正常结算物资入库）。

## 修复（client/src/game.ts）

- 在 Kill 消息处理中检测"本地玩家以 Extraction 伤害类型被移除"：
  - 显示公告"撤离成功，物资已存入仓库"；
  - 1.8 秒后自动跳转到 `/storage`（仓库页），
    玩家可以直接查看带出的物资并重新配装。
- 新增 `extractionSuccessShown` 标记，本局只触发一次，init() 时重置。
- 只对 `DamageType.Extraction` 且目标是本地玩家生效，其他模式不受影响。

## 说明

- 服务端撤离结算（物资入库）本就没问题，本次只补客户端反馈与返回流程。
- 配合 V114 的身份同步，仓库页用与进局一致的身份加载，
  撤离带回的物资可直接看到。

## 验证

- `test:extraction` 通过；client `tsc`、`vite build` 通过。
