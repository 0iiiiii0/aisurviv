# V241 后台仓库管理：显示全部物品（未拥有的显示 0）

## 需求
- 后台玩家仓库管理显示**所有物品**（包括没有的）；
- 未拥有的物品显示 0，并排在「拥有的物品」后面。

## 实现（client/public/admin）
- 新增 `STASH_ITEMS_BY_CATEGORY`：按类别（枪械/近战/弹药/药品/头盔/护甲/背包/
  倍镜/投掷物/能力）列出全部物品；
- `renderStashAdmin` 每个类别渲染**完整清单**：已拥有 + 未拥有（数量 0）；
  排序规则：数量 > 0 的在前，0 的在后，同类按名称排序；
- 未拥有的物品半透明弱化显示（`.stash-admin-item.zero`），加减号仍可操作
  （从 0 起加减）；
- `STASH_SUGGESTED_TYPES` 由该分组表生成，「添加物品」建议列表不变。

## 验证
- admin.js 语法检查通过；client `vite build` 通过（`dist/admin` 已更新）。
