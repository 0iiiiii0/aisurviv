# V178 修复身体部位与游戏内不一致

## 问题

仓库小人各部位（手/脚/头盔/背包/武器）的尺寸与位置和游戏内渲染不符。

## 修复（client/src/storagePlayer.ts，全部按游戏内源码取值）

1. **脚**：游戏内站立时**不显示脚部贴图**（身体贴图已含腿部）→ 隐藏；
2. **手**：缩放由 1.7 改为游戏内实际 **0.175 × k**（约 44px）；
   持枪时用 **rifle 骨骼**（HandL 28,5.25 / HandR 14,1.75），
   空手用 fists 骨骼（14,±12.25）；
3. **头盔**：位置由头顶改为游戏内 **(−3.33, 0)**（身体中心偏左），
   缩放 **0.15 × k**（俯视视角的头顶圆环）；
4. **背包**：位置 (46,18) → 游戏内 **(−10.25, 0)**（身体左后），
   缩放 **0.215 × k**（1 级背包比例）；
5. **武器**：旋转 **90° 水平**、放在左手（rifle HandL）位置，
   与游戏内持枪姿态一致；
6. **层级**：身体 → 护甲 → 头盔 → 背包 → 武器 → **双手**（手盖枪，
   模拟握枪，与游戏内 gun→hand 顺序一致）。

## 验证

- client tsc + vite build：PASS
- 各部位尺寸/位置均取游戏内源码常量（缩放按 k=3.4 放大）
