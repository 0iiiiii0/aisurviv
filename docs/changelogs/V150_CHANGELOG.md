# V150 修复：配置 2077 斯安威斯坦减速时"自动补0"

## 现象
- 后台配置 2077 · 斯安威斯坦的玩家速度/对局速度时，输入值会被自动补零
  （例如输入带小数的值后失焦/保存，显示变成放大 100 倍的数值）。

## 根因
- 输入框失焦归一化逻辑把**百分数输入值（1~100）误当作 0~1 倍率**处理：
  `Math.round(5.5 * 1000) / 10 = 550` —— 5.5% 显示成 550%（补了个 0）；
- 显示公式对浮点伪影（如 35.0000000001）也没有清理。

## 修复（client/public/admin/admin.js appendSandevistanTuning）
1. **失焦归一化修正**：输入框里是百分数，直接清理格式
   （最多两位小数、去尾随 0、去浮点伪影），不再乘以 1000/10：
   - "5.500" → "5.5"；"10.0" → "10"；"35.0000000001" → "35"；
   - 空值恢复为当前配置显示。
2. **显示格式化函数** `formatPercent`：倍率→百分数统一走
   `Math.round(x*1000)/10` 再清两位小数，杜绝浮点伪影。
3. **编辑保护**：自动刷新重渲染重建卡片时，若用户正在编辑该字段，
   恢复焦点与光标，值由 draft 保持，避免输入被打断/值被覆盖。

## 验证（headless Edge 实测）
- 输入 "5.500" → blur → "5.5"（修复前为 550）✅
- 输入 "10.0" → "10"；"35.0000000001" → "35"；"0.10" → "0.1" ✅
- 输入 35 + 2 秒自动刷新 → 值保持 35 ✅
- 保存 "5.5" → 服务器 worldTimeScale=0.055（5.5%），刷新后显示 5.5 ✅
- 配置已恢复 0.5 / 0.1 ✅
- admin.js 语法检查通过 ✅
