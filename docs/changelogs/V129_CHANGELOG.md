# V129 靶场 AI 闪避独立化：消除连射原地抽搐

## 需求

- 靶场（瞄准练习）AI 的闪避要单独处理；
- 即使无法躲避当前子弹也要保持移动（不能被步枪连续命中时站在原地）；
- 修复：被步枪连续命中时 AI 会原地左右抽搐的问题。

## 根因

原 `trainingBulletDodgeDirection()` 每次更新都重新遍历所有子弹：
- 每颗新到的步枪子弹都会重新计算一个垂直方向，并且“朝靶场中心”的
  符号翻转每帧都可能变化；
- 承诺期只有 0.22 秒，连射（30 发/秒）时方向每秒左右翻转几十次
  → 目标原地抽搐；
- 只有“0.85 秒内会命中”的子弹才触发闪避；无法躲避（来不及反应）的
  子弹不会触发移动 → 目标被连续命中时可能原地站立。

## 实现（server/src/game/objects/player.ts，独立状态机）

- 新增专用闪避状态：
  - `trainingDodgeDirection`：承诺的横向闪避方向；
  - `trainingDodgeUntil`：承诺到期时间（260–460ms，按子弹到达时间伸缩，
    点射贴脸也至少有 0.26s 的稳定横移）；
  - `trainingDodgeSide`：当前横向符号，承诺期内符号不随子弹变化；
- **承诺期内不重新选边**：只有子弹轨迹位于我们正移动过去的一侧
  （横向间隙小于角色半径）时才翻转一次，且翻转后重新锁定 300ms；
- **威胁带加宽到 `rad + 4.0`**：即使子弹打不中（近失），目标也会持续
  横移——连射无法把目标“冻住”；
- 新承诺选边：优先远离子弹横向偏移的一侧，其次朝靶场中心，且不直接
  撞向边界；
- 目标重生时重置闪避状态（`resetInternalTrainingMovement`）。

## 验证（aimTrainingSmokeTest 新增 3 组断言）

- 步枪子弹在前方 → 目标触发横向闪避；
- 模拟步枪连射（每 0.05s 一颗新子弹，10 颗）：
  方向翻转次数 ≤ 2（原实现每颗都翻转 → 原地抽搐）；
- 不可躲避子弹（0.02s 命中）→ 目标仍保持移动。
