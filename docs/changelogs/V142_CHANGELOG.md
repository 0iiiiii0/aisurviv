# V142 1v1 邀请链接直达房间（自动加入）

## 需求
- 打开 1v1 邀请链接（?duelLobby=房间号）后直接进入房间，
  省去点击「加入大厅」这一步。

## 实现
`client/src/ui/duelLobby.ts` `init()`：
- 检测到 `duelLobby` 链接参数时，填入房间号并打开大厅；
- 若当前会话不是该房间（或尚无会话），**自动调用 join()** 加入；
- 若已是该房间成员（例如房主自己打开自己分享的链接），直接恢复轮询，
  不会重复加入报错。

## 验证（headless Edge 双浏览器实测）
- 房主创建房间 → 访客直接打开邀请链接：
  - 自动进入房间（room 可见、entry 隐藏）✅
  - 房间内显示 2 名玩家 ✅
  - 无错误提示 ✅
- 房主侧同步看到访客加入 ✅
- client build（tsc + vite）：PASS ✅
