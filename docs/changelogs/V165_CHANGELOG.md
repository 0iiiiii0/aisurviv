# V165 新玩家初始默认物资（新手包）

## 需求

初始默认给一定物资：新玩家首次打开仓库（/storage 或进局）时自动获得
一份新手物资包。

## 实现

### 服务端（server/src/stash/stashManager.ts）
- 新增 `DEFAULT_STARTER_ITEMS` 新手包：
  - 枪械：ak47 ×1
  - 弹药：762mm ×60、9mm ×30
  - 药品：bandage ×3、soda ×1
  - 护甲：helmet01 ×1、backpack01 ×1
  - 投掷物：frag ×1
- `entry()` 仅在**首次创建**玩家仓库记录时写入新手包；
  已存在的玩家（已有 stash 记录）完全不受影响；
- 新手包物品与普通仓库物品同样参与堆叠、带入配装与扣除。

## 验证

- 新玩家首次 GET stash 返回完整新手包 ✓
- 已有玩家不受影响（记录存在时不重新发放）✓
- 新手包可与后续添加物资正常堆叠、随配装扣除 ✓
- test:extraction（新增新手包断言 + 数值更新）：PASS
