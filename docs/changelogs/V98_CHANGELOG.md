# V98 2077 UI 位置调整：局内暗色 / 主界面仅 2077 单人

## 需求

1. 局内（对局内 HUD）不要使用 2077 风格（技能槽恢复暗色）。
2. 主界面选择模式只显示一个"单人"入口，不显示人数/队伍后缀。
3. 主界面按钮不需要额外文字描述，2077 徽章即足够。

## 实现

### 局内技能槽（client/index.html + client/css/game.css）
- 技能槽图标从 2077 数字徽章恢复为暗色圆形 "S"；
- 背景恢复暗色（rgba(10,14,24,.72) + 青紫描边），状态文字/计时/充能条
  恢复浅色与青紫渐变；
- 保留 [中键] 激活提示与冷却/充能条。

### 主界面按钮（client/src/siteInfo.ts）
- 2077·斯安威斯坦 只生成 **单人（Solo）** 入口按钮
  （双人/四人即使开启也不在主界面出现，索引保持不变）；
- 按钮文字改为空，只保留 **2077 数字徽章**（黄底 #FAFE32 + 青蓝数字
  + 连接线，样式来自 V96），不再显示"斯安威斯坦 · 单人"等描述。
