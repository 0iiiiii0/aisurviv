# V109 仓库武器/近战装备后数量 -1，放回加回（预留显示）

## 需求

- 装备武器后仓库数量 -1，放回时 +1。

## 实现（client/src/extractionStashUi.ts）

- 仓库右栏武器/近战卡片数量改为显示"仓库剩余 = 总量 - 已装备"：
  - 左键加一把 → 数量 -1；双持形态按 2 把计。
  - 右键卸一把 / 点击武器槽放回 → 数量 +1。
  - 数量下限 0，不会出现负数。
- `toggleEquip` 增加仓库数量校验：仓库剩余不足时提示
  "仓库中该武器数量不足" / "仓库中没有该近战武器"，不能空手装备。
- × 移除按钮：已装备的武器/近战先提示"请先放回再移除"，
  避免预留数量出现矛盾。

## 说明

- 这是"预留显示"：配装本身就是对仓库的预留，进局发放时才真正扣仓，
  两种口径一致（局内发放后仓库剩余与界面显示一致）。

## 验证

- 场景模拟：ak47 8 把装备 2 把显示 6；m9 5 把显示 5；
  hockey 2 个装备 1 个显示 1；仓库不足时阻止装备。
- client `tsc --noEmit`、`vite build` 通过。
