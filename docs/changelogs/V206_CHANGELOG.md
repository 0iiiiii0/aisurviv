# V206 右键装备类物品改为卸下（不再误删仓库）

## 问题

未装备物品时右键（枪/护甲/背包/倍镜等）会调用仓库移除接口，
导致仓库物品消失。

## 修复（client/src/extractionStashUi.ts + storage.html）

- 新增 `unequip()`：右键装备类物品 = **卸下装备**，
  未装备时无操作，**不删除仓库物品**；
- 覆盖类别：枪械 / 近战 / 头盔 / 护甲 / 背包 / 倍镜；
- 弹药/药品/投掷物右键仍为「携带-1」（不删仓库）；
- 卡片右上角 × 按钮仍保留显式移除功能；
- 提示文案「右键移除」→「右键卸下」。

## 验证

- client tsc + vite build：PASS
- 未装备时右键不再删除仓库物品
