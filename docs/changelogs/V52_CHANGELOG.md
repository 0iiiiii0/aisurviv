# V52 修改清单

## 建筑理解

- 修复建筑和灌木错误读取 `GameObjectDefs` 的问题，改用 `MapObjectDefs`。
- 将建筑的屋顶碰撞或地板表面碰撞转换为世界坐标 AABB。
- `currentBuildingId`、室内治疗、门路线和建筑隐蔽判断改用精确区域。
- 圆形中心/半径仅作为战术距离和缺失定义时的回退，不再作为建筑归属依据。

## 墙体导航

- `NavigationBlocker` 新增真实 Circle/AABB。
- 直接路径检查改为真实碰撞区间。
- 长墙绕行改走 AABB 墙端，而不是绕障碍物中心圆。
- AI 位于墙体膨胀范围内时，先从最近墙面退出。
- 卡住恢复使用真实碰撞区间估算各方向可移动距离。
- 硬掩体阻挡检测改用真实世界碰撞箱。

## 隔墙射击

- 每个网络输入包发送前重新计算最新瞄准射线。
- 实体墙阻挡时取消当帧射击。
- 新增 `gunfire_wall_blocked` 录像事件，记录墙体 ID、类型、瞄准终点和目标。
- 保留合法的掩体破坏、爆炸物、反弹和资源攻击。

## 室内搜索

- 新增精确建筑区域搜索探针。
- 大房间按中心和内缩象限搜索。
- 多房间按最近邻顺序搜索，减少反复横穿。
- 同一建筑内最近资源来源优先于建筑外来源。
- 单个探针长时间无进展时跳过，而不是放弃整栋建筑搜索。
