# V182 统一角色比例：身体/手/武器挂点同步

## 问题

身体圆形被异常放大，手与武器尺寸未同步；手部挂点按旧比例计算，
导致手嵌入身体内部、武器连接位置偏移。

## 修复（client/src/storagePlayer.ts）

### 统一比例基准
- 身体 scale 1.7 → **1.2**（163px，半径 81.6），不再异常放大；
- 手 scale、武器 scale、所有挂点全部以身体半径动态计算。

### 挂点重算（gripOut = 身体半径 + 手半径 + 4）
- 手挂在**身体边缘外侧**（不再嵌入身体）：
  - 持枪：右手 (gripOut, 12)、左手 (gripOut−18, −14)；
  - 空手：双手在身体右前缘上下各一；
- 武器：枪托在右手挂点，向身体外延伸；
- 背包：贴在身体左后缘，尺寸随身体基准；
- 头盔：身体中心（俯视头顶圆环，游戏内位置）。

### 武器缩放同步
- `worldImg.scale × bodyScale`（与身体同一基准），
  步枪约 97px，不再按旧 k 基准过大。

## 验证

- client tsc + vite build：PASS
- 身体/手/武器/背包比例与挂点全部由同一半径派生，无嵌入/偏移
