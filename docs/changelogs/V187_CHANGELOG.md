# V187 角色比例改为参照游戏内实际渲染

## 需求

开一局游戏参照玩家角色与各种装备的真实比例，修正仓库展示。

## 实现（client/src/storagePlayer.ts）

所有参数改为**游戏内实际屏幕比例 × k**（k = 展示身体 150px / 游戏内
身体 68px ≈ 2.206），与游戏内渲染完全同源：

| 部件 | 游戏内（zoom=1） | 展示（×k） |
|---|---|---|
| 身体 | 68px | 150px |
| 手 | 13px（0.175 缩放） | 28.6px |
| 胸甲 | 31px（0.215） | 69px |
| 头盔 | 22px（0.15） | 48px |
| 背包 | 31px（0.215，1 级） | 69px |
| 武器 | worldImg.scale × 0.5 | ×k（AK 约 89px） |

- 挂点：fists/rifle 骨骼坐标、头盔 (−3.33,0)、背包 (−10.25,0)
  全部 = 游戏内数值 × k；
- 手在身体内边缘（与游戏内俯视一致，画在身体上层可见）。

## 验证

- client tsc + vite build：PASS
- 所有部件/挂点与游戏内渲染数值完全同比例
