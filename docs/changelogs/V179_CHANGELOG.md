# V179 修复身体比例问题（枪身不再横穿身体）

## 问题

持枪展示时枪身横穿身体中心（枪中心放在手的位置），看起来身体比例
怪异。

## 修复

### client/src/storagePlayer.ts
- 武器锚点改为 **anchor(0.5, 1)**（贴图底部 = 枪托）并旋转 90°：
  枪托握在左手位置，**枪身向身体外（右）延伸**，
  与游戏内 gun container 行为一致；
- 双手（rifle 骨骼）仍在枪托处握枪（手盖枪）；
- 身体为游戏内俯视圆形贴图，其余参数（手 0.175k、头盔 0.15k、
  背包 0.215k、骨骼位置）均保持游戏内取值。

## 验证

- client tsc + vite build：PASS
- 枪从手部向身体外延伸，不再穿过身体中心
