# V176 小人自动适配画布（整体缩放 + 居中，含枪身长度）

## 需求

确认小人整个身体在框内：自动缩放、调整位置，并考虑枪身长度。

## 实现

### client/src/storagePlayer.ts
- 新增 `fitToFrame()`：以 root 原始坐标计算**全部可见部件**
  （身体 / 手 / 脚 / 头盔 / 背包 / 武器）的包围盒；
- 按画布可用区域（留 14px 边距）计算统一缩放
  `scale = min(1, 可用宽/包围盒宽, 可用高/包围盒高)`；
- 将整体平移到画布中心——长枪（如 m249 / pkp）会让角色整体略微
  缩小，但**永远完整显示在框内**；
- 默认外观与每次配装更新后都会重新适配；
- 纹理未就绪/尺寸异常时安全跳过（try/catch + 有效性检查）。

## 验证

- client tsc + vite build：PASS
- 角色整体（含任意长度武器）始终完整位于画布内且居中
