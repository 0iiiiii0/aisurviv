# V175 携带数量改为 1v1 手雷式加减框

## 需求

携带数量输入框改为后台 1v1 配置手雷数量的那种样式（− 数量 + 加减框），
点一次加减的量与左键/右键一致，同时保留直接填写功能。

## 实现

### client/src/extractionStashUi.ts
- 弹药 / 药品 / 投掷物卡片底部改为 stepper：
  `[−] [数量输入框] [+]`；
- **− / + 按钮**调用 `adjustCarry(±1)`，一次增减 = 与左键/右键相同的
  步长（弹药 30 / 信号弹 1 / .308 5 / 绷带 5 / 其他 1）；
- **中间输入框**保留直接填写（回车/失焦生效，范围 0~仓库总量）；
- 点击/右键按钮或输入框不会误触发卡片自身事件。

### CSS（storage.css + app.css）
- `.stash-stepper` / `.stash-stepper-btn`：后台同款三段式样式
  （深色底、青蓝按钮、隐藏数字微调箭头）。

## 验证

- client tsc + vite build：PASS
- + 一次 = 左键步长；− 一次 = 右键步长；输入框填写保留
