# V103 修复：武器合成双枪时清空 2 号武器槽

## 问题

- 1 号位是 m9、2 号位是其它枪时，点击仓库里的 m9 合成双枪，
  会把 2 号位的武器清空（替换成第二把 m9）。

## 根因

- `toggleEquip` 合成双枪时先"放回另一槽位的其它枪"，再填第二把同型枪：
  当两个槽位都被占用时，会先把另一槽位的武器清掉。

## 修复（client/src/extractionStashUi.ts）

- 合成双枪前检查是否存在空槽：若 1、2 号位已满且另一把是其它枪，
  阻止合成并提示"武器槽已满，请先放回一把武器"，不再清空另一槽位。
- 仍允许的正常流程：有空槽时点击已装备的可双枪武器 → 合成双枪；
  双枪时再次点击 → 卸下一把（保留在 2 号位）。

## 验证

- 场景模拟：
  - `["m9"] + m9 → ["m9","m9"]`（有空槽，合成）
  - `["m9","ak47"] + m9 → ["m9","ak47"]`（阻止，不清 ak47）
  - `["ak47","m9"] + m9 → ["ak47","m9"]`（阻止，不清 ak47）
  - `["m9","m9"] + m9 → ["","m9"]`（双枪卸一把，留在 2 号位）
  - `["ak47","m9"] + groza → ["ak47","m9"]`（槽满阻止添加）
- client `tsc --noEmit`、`vite build` 通过。
