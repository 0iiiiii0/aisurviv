# V247 商店 UI 优化：购买/出售分离、近战仅出售、高品质提价、防卖身上装备

## 需求
- 购买成功后明确提示；
- **近战武器仅允许出售**（不可购买）；
- **提升高品质物品价格**（S+/S/A 武器、3 级护甲、8x/15x 倍镜、稀缺弹药等）；
- **出售单独做**：进入出售时把配装展示界面替换为出售列表；
- **不允许出售身上（已装备/携带）的物品**：如仓库 5 把 AK、身上装 1 把，
  最多只能出售 4 把；
- 出售支持**选择全部**（单个物品一键全选可售数量）；
- 「购买」「出售」按钮放在**确认配装左侧**；
- **批量出售需确认**。

## 实现

### 服务端（economy/shopManager.ts）
- 近战武器硬规则「仅出售」：`effectiveBuyPrice` 对 melee 返回 null（后台设
  买入价也不放开），出售价 = 近战默认价 × 0.5；
- 提升高品质物品价格：
  - 武器：S+ 2000→4000、S 1200→2500、A 800→1500、B 400→600、C 200→300、
    D 100→150；
  - 护甲：1 级 80→120、2 级 250→450、3 级 700→1200；
  - 倍镜：2x 100→150、4x 300→500、8x 800→1500、15x 1500→3000；
  - 仅出售：flare 100→150、flare_gun 300→500、308sub 8→15；
- `shopSell` 新增**防卖身上装备**校验：可出售数 = 仓库总量 − 配装占用
  （枪械含双持折算 2 把、弹药/药品/投掷物按携带数、护甲/近战按装备数）；
  超限返回 `equipped`；
- 目录 `sellOnly` 标记包含近战。

### 客户端（storage / extractionStashUi / storage.ts / storage.css）
- header「确认配装」左侧新增「购买」「出售」按钮，点击直接进入商店对应子视图；
- 商店内分「购买 / 出售」子标签：
  - 购买视图：仅购买按钮（近战/S+/S/信号弹等显示「仅出售」，无购买按钮）；
  - 出售视图：**替换配装展示界面**为可出售物资列表（图片/名称/可售数量/
    单价/数量输入/「全部」），底部批量出售栏显示已选件数与预计收入；
- 出售数量上限 = 可售数量（仓库 − 身上），超过会被限制；
- **批量出售需确认**（列出物品与预计收入），逐项提交后刷新仓库与商店；
- 购买成功高亮提示（`flashStatus` 短暂脉冲动画 + 文案）。

## 验证
- `shopSmokeTest` 更新：近战仅出售、高品质新价格（awc 卖 2000、m4a1 卖 1250、
  8 倍镜买 1500、3 级甲买 1200）、配装占用后超限出售返回 `equipped`、
  卖出除身上外全部后仅剩 1 把；
- server `tsc` PASS；client `vite build` PASS（dist 已更新）。
