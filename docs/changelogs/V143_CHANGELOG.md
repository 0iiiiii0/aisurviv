# V143 确认无多人加入 bug + 满员明确提示

## 需求
- 确认 1v1 不会出现多人加入的 bug；
- 房间满员时给出明确提示。

## 服务端（无并发竞态确认）
`server/src/duelLobby.ts` `join()` 为同步校验，事件循环内无 TOCTOU：
1. 房间不在 waiting（对局中/开始中）→ 「这间1v1大厅正在对局中」；
2. AI 房间 → 「房主已启用 AI 对手，不能再加入真人玩家」；
3. `members.length >= 2` → 「这间1v1大厅已经满员」；
4. 被拒绝的加入不会创建成员、不会改变房间名单。

## 客户端
- 自动加入/手动加入失败时，错误显示在 1v1 弹窗底部红色提示条
  （#duel-lobby-error，含背景高亮样式）；
- 满员提示文案：「这间1v1大厅已经满员」。

## 测试
- `test:duel-lobby` 新增断言：第三名玩家加入被拒、错误消息含「满员」、
  被拒后房间人数仍为 2；
- headless Edge 三浏览器实测：
  - 访客 A 打开邀请链接 → 自动加入成功（2 人）；
  - 访客 B 打开同一链接 → 停留在入口界面，显示
    「这间1v1大厅已经满员」，玩家数 0；
  - 房主侧人数始终为 2（无多人加入）；
- 回归：server tsc / test:duel-lobby / client build 全部 PASS。
