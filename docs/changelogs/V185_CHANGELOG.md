# V185 修正主体半径与附件挂点同步

## 问题

主体外圈半径偏大：背包露出不足、手部嵌入身体边缘、武器握持起点偏内。

## 修复（client/src/storagePlayer.ts）

### 主体缩放
- `bodyScale` 1.2 → **1.0**（身体直径 136px，半径 **68px**）；
- 胸甲随身体同步。

### 附件挂点（全部以 68px 半径重新派生）
- 手挂点 `gripOut = 半径 + 手半径 + 8`（≈98px）——
  手完全在身体外，8px 间隙不再嵌入；
- 背包中心移至 `−(半径 + 12)`（左缘外 12px），**露出面积充足**；
- 武器枪托仍在右手挂点 (98, 12)，向身体外延伸；
- 头盔保持游戏内位置（身体中心俯视圆环）。

## 验证

- client tsc + vite build：PASS
- 主体/背包/手/武器挂点由统一半径派生，无嵌入、露出充分
