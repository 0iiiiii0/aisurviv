# V116 武器进局弹匣装满（用玩家携带的子弹）

## 需求

- 武器子弹要装满，用玩家携带的子弹。

## 实现（server/src/stash/stashManager.ts grantLoadout）

- 进局发放时，每个武器槽的**弹匣按武器自身定义装到满**
  （双枪用双枪自己的弹匣，如 glock_dual 34 发 / an94 45 发），
  子弹从"玩家携带量"中扣除。
- 弹匣填满后的剩余携带量作为**备用弹药**进局（同口径只发一次，
  仍受背包容量限制）。
- 扣仓顺序：先扣弹匣子弹，再扣备用弹药，保证仓库不足时优先装满枪。

## 效果

- 配装 glock_dual + an94、携带 9mm 120 / 762mm 150：
  - 弹匣：34 + 45（全满）
  - 备用：9mm 86 / 762mm 105
  - 仓库：9mm -120 / 762mm -150

## 倍镜核查

- 服务端链路实测：配装 8xscope → 玩家 `scope=8xscope`、`zoom=68`、
  `inventory[8xscope]=1`，并通过更新消息下发客户端（HUD 显示已装备）。
- 之前"疑似没被带入"很可能是仓库倍镜被消耗（进局发放扣仓、阵亡丢失），
  库存不足时该倍镜被跳过；本次已把测试期间误扣的仓库物资恢复。
