# V198 配装阶段校验提示

## 需求

配装时给出不同提示：
- 带枪但未带对应弹药 / 弹药不足（至少 3 个弹匣）；
- 带枪但未带医疗物品；
- 仓库内无该类型物品则不提示。

## 实现

### client/src/extractionStashUi.ts
- 新增 `loadoutWarnings()`，在每次保存配装（persistLoadout）后校验：
  - 每把已带枪械：仓库有对应弹药时，未携带 → 
    「XX 未携带 XX 弹药」；携带 < 弹匣容量 × 3 → 
    「XX 弹药不足（建议 ≥N 发，当前 M）」；
  - 带枪且仓库有医疗物品（heal/boost）但未携带任何药品 →
    「未携带医疗物品（绷带/医疗包/汽水等）」；
  - 仓库无对应弹药 / 无医疗物品 → 不提示；
- 有提示时状态栏红色显示「配装已保存，注意：…」，
  无提示显示绿色「配装已保存」。

## 验证

- client tsc + vite build：PASS
- 弹药按各枪弹匣容量 ×3 计算（AK 90 发、MP5 90 发等）
