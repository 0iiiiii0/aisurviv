# V18：观战自由视角与混合 AI 难度

本版本基于 V17 完整项目制作。

## 观战切换

常规模式、单排、双排、四排、50v50 和 1v1 均显示以下观战控制：

- 上一位玩家
- 下一位玩家
- 自由视角 / 玩家视角
- 查看比赛统计
- 离开游戏

服务器会将存活真人排在可观战列表前面。只有没有可用真人镜头时，才会继续切换到服务器 AI。

自动重新分配镜头时同样遵循真人优先，包括当前目标死亡、断线或离开房间的情况。

## 自由视角

点击“自由视角”后可脱离玩家镜头：

- `WASD` 或方向键：移动
- `Shift`：快速移动
- 鼠标中键或右键拖动：平移镜头
- 鼠标滚轮或 `+` / `-`：放大和缩小
- 再次点击按钮：返回玩家视角
- 点击上一位或下一位：退出自由视角并切换玩家

自由视角位置由服务器校验并限制在地图范围内。服务器仅同步镜头附近对象，不会借此获得整张地图的隐藏信息。

## AI 难度调整

移除原来的最低档 `easy`，现在仅保留：

- `normal`：普通
- `hard`：困难
- `pro`：职业级

`Pro` 相比困难 AI：

- 思考和反应间隔更短
- 瞄准抖动更小
- 移动目标提前量更准确
- 目标记忆时间更长
- 战斗搜索范围更大
- 转向、侧移、撤退和治疗决策更积极

仍保留瞄准转向速度限制，不会恢复一帧拉枪。

## 常规服务器混合难度

自动补入的 AI 按以下循环生成：

```text
normal → hard → normal → pro → hard → normal
```

长期比例约为：

- 普通：50%
- 困难：33%
- Pro：17%

机器人名称会显示对应等级，例如 `AI-normal`、`AI-hard`、`AI-pro`。

50v50 的阵营分配、每两秒进入一个 AI、双方人数上限及后台配置规则保持不变。

## 1v1 难度选择

1v1 房间启用 AI 对手后，可在房间设置中选择：

- 普通
- 困难
- Pro

房主保存设置后，生成的 1v1 AI 会严格使用选择的难度，不参与常规房间的混合轮换。

## 协议变更

观战消息新增自由视角状态、镜头位置和视野半径，网络协议版本由 78 更新为 79。客户端与服务端必须同时覆盖并重启，不能混用旧版本。

## 静态客户端说明

Windows 启动器默认运行 Vite 开发服务，会直接使用本版本的客户端源码。若使用预构建的 `client/dist` 静态目录，需要在 Windows 的 `client` 目录运行：

```powershell
npm run build
```
