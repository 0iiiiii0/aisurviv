# 1v1 视野、沙袋追击与后台观战修复

## 修复内容

### 1. AI 视野与正常玩家一致

- 直接索敌只使用服务端同步的当前 `zoom` 和当前装备倍镜。
- 背包中未装备的高倍镜只参与武器评分，不再扩大索敌画面。
- 视野矩形按正常客户端 16:9 摄像机计算，并保留小幅安全内缩。
- 玩家不在当前画面或被实体掩体遮挡时，不更新其精确位置记忆。

### 2. 沙袋后不再抽动

- 敌人进入沙袋后，AI 锁定一侧绕行点约 1.65 秒，不再每个思考周期重新左右选边。
- 只有受到来弹压力时才加入轻微侧移；普通搜索采用稳定直线接近。
- 绕行点会检查地图边界和毒圈，首选方向无效时切换另一侧。

### 3. 1v1 主动寻找玩家

- 内置 Duel 地图使用真实镜像出生位：`(0.2W, 0.5H)` 与 `(0.8W, 0.5H)`。
- 自定义紧凑竞技场使用玩家出生点的水平镜像作为公平的初始搜索假设。
- 看见敌人后仅记忆最后可见位置；目标消失后优先搜索该位置并绕开阻挡沙袋。
- 1v1 搜索和侧翼逻辑提前到通用决赛圈站位之前，避免目标隐藏后 AI 放弃接近。

### 4. 后台观战

- 管理员观战者增加独立 `spectatorOnly` 身份。
- 观战者不会加入 `livingPlayers`，不会成为回合选手或影响比分。
- 每回合重置只重置两名参赛者，观战者保持死亡状态并重新绑定存活目标。
- 发送更新时同时保证观战者自身对象和当前镜头目标对象存在。
- 观战目标死亡且回合正在切换时，不会把镜头切回观战者尸体。
- 无队伍的后台观战者可以安全使用上一位/下一位切换。

## 新增测试

```powershell
npm --prefix server run test:duel-vision
npm --prefix server run test:duel
```

测试覆盖当前倍镜视野、敌方出生位推断、稳定沙袋侧翼、观战目标前后切换、五局制重置以及观战者不参与胜负。
