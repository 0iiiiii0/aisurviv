## 已实施的改进

### 1. 可见威胁监督层

新增 `server/src/bot/spectatorSupervisor.ts`。它位于治疗安全检查之后、送弹、空投、编队、集合和其他自愿任务之前。

当近距离敌人可见时：

- 持枪 AI 会中断拾取、破箱、集合、空投操作、送弹、探索和躲藏，转入战斗。
- 900 ms 内刚受到攻击时扩大中断距离；420 ms 内被击中时优先反击。
- 无枪 AI 在敌人贴近或刚受伤时进入 `evade-and-search`，先拉开距离并继续寻枪。
- 正常反应延迟仍保留，不会变成无条件瞬间锁敌。
- 毒圈、最高优先级空袭和已经拉开保险的投掷物不会被监督层错误打断。

新增事件：

```text
visible_threat_interrupt
```

事件会记录原状态、原意图、敌人距离、是否刚受伤、响应类型和原因。

### 2. 战略目标失败退避

过去资源目标有拉黑机制，但集合点、编队槽位、阵营命令、敌人搜索点和特殊角色目标可以在卡路后立刻重新选择。

现在同一战略目标累计 3 次恢复后：

- 清除当前意图；
- 对该目标应用 13.9–24 秒退避；
- `weapon-search`、`explore` 和 `enemy-search` 强制生成不同路线；
- 仅屏蔽低优先级、带目标键的战略意图；
- 战斗、治疗、救援、毒圈和空袭不会被过滤。

新增事件：

```text
intent_progress_abandoned
```

### 3. 决策候选过滤

所有普通意图进入 `decisionBrain.choose` 前都会过滤仍处于退避期的失败目标。如果全部候选都被过滤，AI 会生成一个新的探索点，而不是继续使用原目标。

### 4. 记录器升级到 V4

下一批记录会明确包含：

- `visible_threat_interrupt`
- `intent_progress_abandoned`
- 原状态和原意图
- 原目标键
- 卡路次数和退避时间
- 监督层响应类型

这样可以逐 AI 判断：监督层是否触发、是否被生存状态正确保护、失败目标是否真的换掉。

### 5. 可重复的逐 AI 分析工具

新增：

```text
tools/ai_spectator_analyzer.py
```

它会完整读取所有 manifest、frames 和 events，并为每个 AI 生成 Markdown、HTML 和机器可读 JSON 报告。
