## 2. 日志中确认的问题

### 2.1 建筑外壳没有被当作连续碰撞体

共记录到 **2,308 次卡路恢复**，其中 **1,730 次（74.96%）**发生在建筑外墙、仓库墙、集装箱墙或棚屋外壳附近。

旧导航逻辑大量使用固定约 `2.1` 的圆形半径近似长矩形墙段。长墙两端因此会出现几何上的“假缺口”，AI 判断路线可通行，但实际玩家碰撞体无法穿过，随后持续撞墙和恢复。

高频外壳卡点：

| 外壳类型 | 恢复次数 |
|---|---:|
| `warehouse_wall_edge` | 183 |
| `brick_wall_ext_4` | 144 |
| `brick_wall_ext_16` | 140 |
| `shack_wall_side_left` | 138 |
| `warehouse_wall_side` | 111 |
| `brick_wall_ext_3` | 106 |
| `brick_wall_ext_9` | 86 |
| `brick_wall_ext_5` | 56 |
| `container_wall_top` | 56 |
| `metal_wall_ext_8` | 55 |


**V27 修复：**

- 导航障碍物半径改为根据真实碰撞 AABB 的对角半径计算。
- 仓库外墙模拟半径由错误小圆修正为 `3.256`。
- 建筑入口寻路会先识别目标所属屋顶/建筑，再选择该建筑可用门。
- 区分“进入目标建筑”“同楼层跨房间”“离开当前建筑”三种路径。
- 门目标带稳定锁，避免在相邻建筑门之间反复切换。
- 记录器 V3 会写入当前建筑、屋顶、入口门和房内路线门。

### 2.2 AI 长时间追逐不可达武器或箱子

日志中存在 **4,236 段资源追逐**。最严重的 `weapon-search` 目标持续 **170.442 秒**。此外有 **4,385 个停滞窗口**。

资源放弃事件原因：

| 原因 | 次数 |
|---|---:|
| 无距离进展 | 492 |
| 重复卡路恢复 | 83 |
| 承诺时间超时 | 19 |

同一对象会被反复选回；例如 `crate:7141` 被放弃 **72 次**。旧版短暂拉黑结束后，评分器会立即重新选择同一不可达目标。

**V27 修复：**

- `weapon-search` 使用独立总时限和无进展时限。
- 50v50 的武器区域搜索通常最多约 12 秒，不再持续数分钟。
- 每次失败提高该目标的失败计数，采用指数退避，最长拉黑 90 秒。
- 只有真正缩短到目标的距离才重置进展，不把横向摆动算作进展。
- 毒圈或空袭紧急状态会立即清除旧资源目标，不允许恢复逻辑回头。

在记录策略重放中，长 `weapon-search` 段：

| 指标 | 日志旧行为 | V27 策略上限 |
|---|---:|---:|
| 纳入重放的长追逐段 | 38 | 38 |
| 总持续时间 | 605,743 ms | 335,519 ms |
| 最长单段 | 170,442 ms | 12,000 ms |
| 总时长下降 | — | 44.6% |

该结果是对真实时间线应用新超时策略的**策略重放**，不是完整物理对局重演。

### 2.3 多名 AI 长时间没有枪

- **17 个 AI**在记录结束前始终没有获得枪。
- **25 个 AI**超过 30 秒仍无枪。
- 最长无枪时间为 **319.313 秒**。

原因包括：建筑外壳假通路、武器区域搜索无独立超时、阵营任务抢占、重复选择失败资源，以及空投载荷未进入通用资源评分。

**V27 修复：**

- 保留 V26 的模式隔离和“无枪优先寻枪”。
- 修复建筑入口和区域搜索超时。
- 扩大安全条件下的高价值资源评分。
- 对高价值空投载荷允许使用合适枪械远程破坏，避免只会拿近战慢慢敲或完全忽略。

### 2.4 可破坏资源利用不足，但不能无差别攻击家具

日志附近机会中：

| 对象 | 附近机会帧 | 目标帧 | 结论 |
|---|---:|---:|---|
| `crate_04` | 4,178 | 0 | 真正遗漏；有装甲要求，应在具备合适近战时使用 |
| `crate_06` | 620 | 0 | 真正遗漏；同样需要能力检查 |
| `crate_14` | 239 次空投/资源观测 | 0 | 真正遗漏；投掷物资源箱应提高优先级 |
| `refrigerator_01` | 782 | 0 | 不可破坏，不应作为资源目标 |
| `oven_01` | 515 | 0 | 可爆炸但无资源，不应主动靠近破坏 |
| `barrel_01` | 4,009 | 0 | 可爆炸但无资源，主动破坏可能自伤 |

**V27 修复：**

- 提高投掷物箱、弹药箱及高收益资源箱的评分。
- 装甲箱只有在 AI 具备能破坏它的近战武器时才会选择。
- 对空投高价值载荷，可在安全且弹药充足时使用适合的非发射器枪械破坏。
- 冰箱、烤箱、油桶等假资源候选明确排除，避免把“利用资源”错误实现为攻击所有家具。

### 2.5 空投外壳与载荷没有被充分利用

日志观测到：

- 活着的 `crate_14` 最少距离约 22.2，但目标帧为 0。
- `airdrop_crate_03` 和 `crate_12` 出现在附近对象中，但目标帧为 0。
- 旧识别规则过窄，并且部分利用逻辑偏向 50v50 专用链。

**V27 修复：**

- 标准空投外壳统一支持 `airdrop_crate_01`–`04`。
- 高价值载荷统一支持 `crate_10`–`13`。
- 普通、双人、四人、活动模式和 50v50 均可在安全条件下利用空投。
- 空投评分同时考虑敌人威胁、毒圈、已有装备、破坏能力、目标拥挤和距离。
- 已开启空投残留物不会再次被错误当成需要长期防守的活动空投。

### 2.6 单次空袭警告链不完整

本批日志中：

- `airstrikeZones` 有效帧：**0**。
- 空袭相关事件：**0**。
- 受伤事件有 1,213 次，但旧记录无法判断是否来自单次地图空袭。

这暴露出两个问题：

1. 地图/飞机调度的单次空袭没有像信标空袭一样稳定进入 AI 的警告数据。
2. 记录器无法写出首次落弹倒计时、高杀伤核心和实际撤离路线。

因此，不能仅凭这批日志直接回放空袭；V27 同时核对了服务端空袭源代码路径，并建立确定性模拟验证。

**V27 修复：**

- 服务端机器人现在会接收信标空袭和地图/飞机单次空袭的警告。
- 威胁数据包含推导出的首次落弹倒计时、完整危险半径和高杀伤核心半径。
- 当 AI 位于即将落弹的高杀伤核心时，撤离是**绝对最高优先级**，位于：毒圈、战斗、治疗、救援、拾取、编队和特殊角色任务之前。
- 紧急撤离会取消治疗、救援、资源追逐、空投防守和待执行特殊动作。
- 路线不会只沿单一径向逃跑；若直线路径被墙或建筑阻挡，会尝试多个侧向出口。
- 高优先级撤离目标必须位于完整危险半径之外，并保留额外安全边距。
- 保持现有三字段客户端空袭协议，不改变生产客户端数据流。

确定性模拟结果：

| 项目 | 结果 |
|---|---:|
| 高杀伤核心判定为最高优先级 | 是 |
| 模拟首次落弹倒计时 | 650 ms |
| 直线路径受阻后找到替代路线 | 是 |
| 单次空袭核心内 AI | 40 |
| 成功路由到完整危险区外 | 40 |

### 2.7 从日志额外发现的问题

#### 战斗状态占比异常低

行为状态中 `combat` 仅 329 帧，而 `gas` 有 7,947 帧、`loot` 有 7,038 帧、`regroup` 有 3,104 帧。这与无枪、路径停滞和阵营任务抢占共同相关。V27 通过缩短失效资源追逐、提高可用空投/箱子利用和紧急状态清理，减少无效前置状态占用。

#### 伤害来源记录不完整

`damage_taken` 共 1,213 次，主要发生在 `gas` 和 `regroup` 状态。V27 在受伤事件中加入当前空袭上下文和“可能为空袭伤害”的标记，便于下一批日志区分毒圈、枪击、爆炸和空袭撤离失败。

#### 记录器对建筑与空投缺乏决策上下文

记录器升级到 V3，新增：

- 空袭倒计时、完整半径、高杀伤核心和撤离目标。
- 当前建筑/屋顶、入口门和室内路线门。
- 武器搜索持续时间和无进展时间。
- 资源失败次数与退避时长。
- 空投外壳/载荷交互及破坏方式。
- 受伤时的空袭上下文。

1. 日志确认旧记录/警告链为空。

3. 将单次空袭接入服务器机器人警告链。
4. 用 40 AI 确定性模拟验证最高优先级和危险区外路线。
5. 运行全部 39 项回归测试。
