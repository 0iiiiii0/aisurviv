# Surviv.io 全模式 AI 适配

本版本在原有 1v1、全地图、50v50、特殊兵种、弹道、掩体、物资、毒圈和观战功能上，新增统一的 **ModeStrategy 模式适配层**。AI 不再只根据地图名执行少量特判，而是同时读取：

- 当前地图 ID
- 服务器真实 `TeamMode`
- 地图 `gameMode` 标志
- 最大人数、阵营、职业、狙击、土豆、森林、沙漠、火鸡等规则
- 是否允许拾取、破箱、救援和小队协作

- Desert：单人、双人、四人
- 50v50

未知自定义地图会进入 `custom` 安全回退，而不会退化为无目标随机移动。

## 队伍规则

### 单人

- 不执行救援或编队。
- 更独立地搜索武器、药品和掩体。
- 决赛圈减少无意义绕行，优先保命和第三方机会。

### 双人

- 两人紧密但不重叠。
- 提高倒地救援权重。
- 共享目标、弹药需求和资源预留。
- 一人救援时另一人负责掩护。

### 四人

- 队长、突击、支援、侦察角色分工。
- 阵型间距、小队凝聚、集火、救援和补给协同。
- 提高团队弹药储备，避免全队争抢同一物资。

### 50v50

- 使用真实 `teamId` 进行阵营级协调。
- 桥梁、前线、侧翼、火力、医疗、预备队和特殊兵种分工。
- 提高军事空投、角色物资、弹药和救援优先级。

### 1v1

- 保留现有固定出生装备、沙袋侧翼、可破坏掩体、初始位置搜索、可选激素和毒圈策略。
- 完全关闭拾取和物资箱收益逻辑。

## 地图与活动模式策略

### Desert / Savannah

- 扩大有效战斗扫描距离。
- 提前转圈，减少开阔地停留。
- 偏好狙击枪、DMR、高倍镜和充足远程弹药。

### Woods 系列

- 缩短理想交战距离。
- 偏好霰弹枪、冲锋枪和植被掩护。
- 提高近距离伏击、侧翼和箱子搜索权重。

### Potato 系列

- 提高枪械更换、弹药储备、物资搜索和破箱意愿。
- 对频繁武器变化重新计算当前最佳武器。

### Cobalt

- 识别 `perkMode`。
- 提高 Class Pod、Perk 和职业匹配装备优先级。
- 保留职业选择与 Perk 自适应战斗逻辑。

### Turkey / Halloween / Snow

- Turkey：活动物资和事件容器优先。
- Halloween：近距离伏击、活动物资和特殊近战偏好。
- Snow：开阔地远程判断和雪球武器距离适配。

### 季节地图

- 保留 Normal/Potato/Woods 主家族策略。
- 同时使用实时地图分析处理不同建筑、河流、植被和资源生成结果。

## 后台加入 AI

后台“加入 AI”现在支持所有运行中的房间，不再限定 1v1：

- 自动查找房间对应的播放列表索引。
- 自动传递真实地图和队伍模式。
- 单人使用 1 人令牌。
- 双排/四排使用服务器自动补队规则。
- Faction 自动启用阵营 AI。
- Duel 自动启用 1v1 策略与房间激素规则。

AI 仍通过正常 WebSocket 玩家协议加入，不直接修改服务器中的伤害、速度、命中、毒圈或物资判定。

## 文件

- `server/src/bot/modeStrategy.ts`：统一模式策略。
- `server/src/allModesSmokeTest.ts`：47 播放列表专项测试。
- `MODE_PROFILES_ALL_MODES.json`：全部播放列表的解析结果。
- `server/src/smartBot.ts`：模式策略接入。
- `server/src/gameServer.ts`：后台通用加入 AI。
