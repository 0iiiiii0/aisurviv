# V20 后台人数统计、明文密码与毒圈逃离

## 后台人数拆分

后台总览和房间列表不再只显示一个混合人数：

- 真人玩家：已连接的真人参赛者，包括死亡后仍留在对局中的真人。
- AI 玩家：服务器生成并仍保持连接的人机。
- 纯观众：通过后台观战等方式进入、但不作为参赛者的连接。
- 房间列表另外保留“存活人数 / 地图上限”。

服务端多进程模式会把三项计数随房间状态同步到主进程，后台接口和前端显示使用同一组权威数据。

## 后台密码明文存储

密码文件仍位于项目根目录之外的网页静态目录：

```text
survivio-admin-auth.json
```

V20 新格式：

```json
{
    "version": 2,
    "password": "你的管理员密码"
}
```

- 登录接口不会把密码返回给浏览器。
- 文件不会由网页服务器作为静态文件公开。
- 旧版 `version: 1` 的 scrypt 哈希文件仍能登录；首次成功登录后会自动迁移为明文格式。
- 在后台修改密码后，所有旧管理会话仍会立即失效。
- 明文存储降低了本机文件泄露时的安全性，应限制项目目录和远程桌面账户权限。

## 毒圈逃离重构

- 修复等待阶段错误插值安全区的问题：等待阶段使用当前圈，只有收圈阶段才进行位置和半径插值。
- 同时考虑当前安全区和下一阶段安全区，避免进入当前圈后马上又被下一圈甩在外面。
- 根据剩余收圈时间、到安全位置的预计路程和卡住状态决定是否提前转移。
- 为每次逃圈生成多个候选点，包括最近内圈点、下一圈内点、中心点和左右切向绕行点。
- 对候选点执行障碍物和局部寻路评估，直线路线被建筑挡住时会选择侧面路线。
- 地图导航器继续负责河流、桥梁、岸线和开阔地修正。
- 连续约 1.25 秒没有接近目标时，立即废弃当前逃圈点并换另一侧路线。
- 真正在毒圈外或下一圈即将压到时，逃圈优先级高于搜刮、治疗、救援和普通追击。
