# V16：普通模式统一AI上限、卡死恢复与无人房间关闭

## 普通模式统一AI上限

后台中的单排、双排和四排共用一个“普通模式统一AI上限”。该值是每个房间的AI硬上限，不是所有房间合计的全服上限。

- 修改统一上限后，单排、双排、四排立即使用同一个数值。
- 各模式仍可分别设置加入间隔和房间补齐目标。
- 50v50继续使用独立的总AI上限，并平均分配至两个阵营。
- 读取V15旧配置时，会取普通模式旧上限中的最大值作为统一值，并删除旧的逐模式AI上限字段。

## AI卡死恢复

旧逻辑主要依赖随机换方向，遇到墙角、狭窄家具、门框或近似碰撞半径重叠时，可能反复选择仍不可通行的方向。

V16改为分级恢复：

1. 检测前方、两侧、斜后方和后方的实际可通行距离。
2. 第一次卡住优先沿障碍物侧面绕行。
3. 连续失败时更换绕行侧，并允许后撤脱离夹角。
4. 第三次失败后释放并临时屏蔽当前不可达物资或资源箱。
5. 多次失败后更换探索目标，避免再次返回同一死点。
6. 除完全不移动外，还检测3.2秒内净位移过小的来回震动。
7. 室内优先寻找当前建筑的可用门；门不可达时将该门临时加入黑名单。

恢复方向会保持一段时间，不会每个思考周期左右切换。

## 只剩AI且无人观看时关闭房间

非1v1房间在曾有真人连接后，如果只剩服务器AI并且没有任何真人连接，会在2.5秒重连宽限后关闭。

以下连接均算“有人观看”，不会关闭：

- 存活真人玩家
- 已死亡但仍在观战的真人玩家
- 以纯观众身份进入的真人

限制：

- `duel` 1v1房间不应用该规则。
- 从未有真人成功连接的房间不会仅因AI先进入而被关闭。
- 关闭的是游戏房间；多进程模式中的空闲游戏进程仍可由管理器复用。
